# Logging and Monitoring in Google Cloud

## Course Overview

This course introduced the fundamentals of observability, monitoring, logging, alerting, and incident management in Google Cloud. It focused on using Google Cloud Operations Suite to collect, analyze, and visualize metrics and logs, enabling organizations to maintain reliable and highly available cloud applications.

Through hands-on labs and practical exercises, I learned how to monitor infrastructure, configure uptime checks, create alerting policies, investigate incidents, analyze logs, and build custom dashboards.

---

## Learning Objectives

* Understand the principles of cloud observability.
* Explore the Four Golden Signals of monitoring.
* Use Google Cloud Monitoring to collect and analyze metrics.
* Use Cloud Logging to investigate application and infrastructure events.
* Configure Uptime Checks and Alerting Policies.
* Create Monitoring Groups and Metrics Scopes.
* Build custom dashboards for operational visibility.
* Investigate incidents and alerts.
* Monitor application performance and latency.
* Apply Site Reliability Engineering (SRE) monitoring concepts.

## Key Concepts Learned

### Metrics Scope

A Metrics Scope enables centralized monitoring across multiple Google Cloud projects from a single monitoring project.

### Monitoring Groups

Monitoring Groups allow resources to be organized logically using labels and filtering criteria.

### Uptime Checks

Uptime Checks continuously verify service availability and response health from multiple global locations.

### Alert Policies

Alert Policies automatically generate incidents when predefined conditions are violated.

### Cloud Logging

Cloud Logging provides centralized storage and analysis of logs generated by applications and cloud resources.

### Metrics Explorer

Metrics Explorer helps visualize and analyze metrics collected from cloud infrastructure and applications.

### Incident Management

Incidents represent active monitoring issues that require investigation and resolution.

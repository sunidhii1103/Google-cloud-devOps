# Google Cloud Fundamentals: Core Infrastructure ☁️

This repository contains my notes, hands-on labs, and learnings from the **Google Cloud Fundamentals: Core Infrastructure** course by Google Cloud.

## 📚 Course Overview

This course introduced the fundamentals of cloud computing and core Google Cloud services including:

* Compute Engine
* Virtual Private Cloud (VPC)
* Cloud Storage
* Cloud SQL
* Kubernetes & GKE
* Cloud Run
* IAM & Resource Hierarchy
* Generative AI & Gemini

The course also included practical hands-on labs using real Google Cloud resources.

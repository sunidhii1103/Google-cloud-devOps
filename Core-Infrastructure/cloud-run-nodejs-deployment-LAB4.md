# Deploying a Containerized Node.js Application on Cloud Run

## Lab Objective

In this lab, I enabled Cloud Run and Artifact Registry APIs, created a Node.js application, containerized it, uploaded the container image to Artifact Registry, and deployed the application on Cloud Run.

---

# Services Used

* Cloud Run
* Artifact Registry
* Cloud Shell
* Node.js

---

# Tasks Performed

* Enabled Cloud Run API
* Enabled Artifact Registry API
* Created a simple Node.js application
* Built and containerized the application
* Uploaded the container image to Artifact Registry
* Deployed the application on Cloud Run
* Cleaned up unused images

---

# What I Learned

* Basics of serverless container deployment
* Containerization using Docker concepts
* Managing container images with Artifact Registry
* Deploying stateless applications on Cloud Run
* Understanding serverless architecture

# Key Concepts

Successfully deployed a containerized Node.js application on Google Cloud Run using Artifact Registry.

# Deploying a LAMP Stack using Google Cloud Marketplace

## Lab Objective

In this lab, I used Google Cloud Marketplace to deploy a LAMP stack on a Compute Engine virtual machine.

The Google Click-to-Deploy LAMP Stack provided a ready-to-use web development environment for Linux.

---

# Services Used

* Google Cloud Marketplace
* Compute Engine
* Linux VM

* Understanding the LAMP stack:

  * Linux
  * Apache
  * MySQL
  * PHP
* Accessing applications hosted on a VM instance

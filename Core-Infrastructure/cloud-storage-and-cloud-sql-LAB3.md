# Integrating Cloud Storage and Cloud SQL with a Web Application

## Lab Objective

In this lab, I created a Cloud Storage bucket and uploaded an image into it.

I also created and configured a Cloud SQL instance, connected it to a web server, and displayed the image from Cloud Storage on a web page.

---

# Services Used

* Cloud Storage
* Cloud SQL
* Compute Engine

---

# Tasks Performed

* Created a Cloud Storage bucket
* Uploaded image files into the bucket
* Created and configured a Cloud SQL instance
* Connected the database to a web server
* Displayed stored images on a web page

---

* Database management using Cloud SQL
* Connecting cloud databases to applications
* Integrating storage services with web applications
* Hosting application assets in cloud storage

Successfully connected Cloud Storage and Cloud SQL services with a web application hosted on Google Cloud.

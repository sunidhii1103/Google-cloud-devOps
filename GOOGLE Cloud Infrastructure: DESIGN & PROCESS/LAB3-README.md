# Monitoring Applications in Google Cloud

## Overview

This lab demonstrates how to deploy an application on Google Cloud and monitor its performance, availability, and behavior using Google Cloud Operations Suite tools. The lab focuses on observability, troubleshooting, and proactive monitoring through logging, tracing, profiling, dashboards, uptime checks, and alerting policies.

---

## Objectives

In this lab, I learned how to:

- Download a sample application from GitHub
- Deploy an application to Google App Engine
- Analyze application logs using Cloud Logging
- Monitor application performance with Cloud Profiler
- Trace requests using Cloud Trace
- Visualize metrics through Cloud Monitoring Dashboards
- Create Uptime Checks
- Configure Alerting Policies

## Task 1: Download Sample Application

### Purpose

Obtain the sample application source code from GitHub.

### Steps Performed

1. Opened Google Cloud Shell.
2. Cloned the sample application repository from GitHub.
3. Navigated to the project directory.

### Outcome

The application source code became available locally for deployment.

---

## Task 2: Deploy Application to App Engine

### Purpose

Deploy the application to a managed serverless platform.

### Steps Performed

1. Configured App Engine.
2. Deployed the application using:

```bash
gcloud app deploy
```

3. Opened the deployed application URL.

### Outcome

The application was successfully deployed and accessible through App Engine.

### Benefits of App Engine

- Fully managed platform
- Automatic scaling
- Integrated monitoring
- No server management required

# Reliable Google Cloud Infrastructure: Design and Process

## Course Overview
This course focuses on designing reliable, scalable, secure, and cost-effective cloud systems on Google Cloud Platform (GCP). It emphasizes cloud architecture, system design, reliability engineering, and decision-making for real-world applications.

## Topics Covered
- Cloud Architecture & Design
- Microservices Architecture
- Requirement Gathering
- DevOps & Automation
- Google Cloud Storage Services
- Deployment Strategies
- Network Design
- Reliability & High Availability
- Disaster Recovery
- Cloud Security
- Monitoring & Logging

## Key Learnings
- Designed cloud-native applications using microservices
- Learned how to choose appropriate compute and storage services
- Understood reliability concepts like availability and durability
- Explored deployment options:
  - Compute Engine
  - Kubernetes Engine
  - App Engine
- Implemented security best practices using Google Cloud
- Learned monitoring and observability techniques using logs, dashboards, and tracing

## Google Cloud Services Explored
- Google Compute Engine
- Google Kubernetes Engine (GKE)
- App Engine
- Cloud Storage
- Cloud Monitoring
- Cloud Logging

## Skills Gained
- Google Cloud Platform (GCP)

Gained practical knowledge of designing production-ready cloud infrastructure and understanding how reliable systems are built and maintained on Google Cloud.
